# 🎓 Öğrenci Bilgi Sistemi

Bu proje, **Veritabanı Yönetim Sistemleri dersi kapsamında final projesi** olarak geliştirilmiş bir web tabanlı Öğrenci Bilgi Sistemi uygulamasıdır.

Projenin temel amacı; öğrencilerle ilgili bilgilerin düzenli bir şekilde saklanması, yönetilmesi ve kullanıcıların ihtiyaç duyduğu öğrenci bilgilerinin sistem üzerinden görüntülenebilmesini sağlayan bir yapı oluşturmaktır.

---

## 📌 Proje Hakkında

Öğrenci Bilgi Sistemi; öğrenci bilgilerinin dijital ortamda yönetilmesini amaçlayan, web tabanlı bir uygulamadır.

Proje geliştirilirken özellikle **veritabanı tasarımı, veri yönetimi ve web uygulaması ile veritabanı arasındaki bağlantı** konularına odaklanılmıştır.

Bu proje sayesinde ders kapsamında öğrenilen veritabanı konuları gerçek bir uygulama senaryosu üzerinde uygulanmıştır.

---

## 🎯 Projenin Amacı

Projenin temel amaçları:

- Öğrenci bilgilerinin sistematik şekilde saklanması
- Öğrenci kayıtlarının yönetilebilmesi
- Verilerin web arayüzü üzerinden görüntülenebilmesi
- Veritabanı ile web uygulaması arasında bağlantı kurulması
- Veritabanı işlemlerinin gerçek bir proje üzerinde uygulanması
- Kullanıcıların öğrenci bilgilerine daha düzenli şekilde erişebilmesi

## 🗄️ Veritabanı

Projenin önemli bölümlerinden biri veritabanı yapısıdır.

Öğrenci bilgilerinin kalıcı olarak saklanması ve uygulama üzerinden yönetilebilmesi amacıyla ilişkisel veritabanı yaklaşımından yararlanılmıştır.

Proje kapsamında veritabanı dersinde öğrenilen;

- Tablo oluşturma
- Veri ekleme
- Veri güncelleme
- Veri silme
- Veri listeleme
- SQL sorguları
- Tablolar arası ilişkiler
- Veri bütünlüğü
- CRUD işlemleri

gibi temel veritabanı konuları uygulamaya aktarılmıştır.

---

⚙️ Projeyi Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak için:

1. Repository'yi klonlayın
git clone https://github.com/meliksah-camgoz/OgrenciBilgiSistemi.git
2. Visual Studio ile açın

OgrenciBilgiSistemi.sln dosyasını Visual Studio ile açın.

3. Veritabanını oluşturun

Projenin çalışabilmesi için gerekli veritabanının oluşturulması ve bağlantı bilgilerinin proje yapılandırmasına uygun şekilde ayarlanması gerekmektedir.

4. Bağlantı ayarlarını kontrol edin

Web.config içerisindeki veritabanı bağlantı bilgilerinin kendi SQL Server ortamınıza göre düzenlenmesi gerekir.

5. Projeyi çalıştırın

Visual Studio üzerinden projeyi çalıştırarak web uygulamasına erişebilirsiniz.
